AI 客服聊天窗 · 演示

右下角就是聊天窗。点下面的问题直接发进去，看它怎么答——能答的自己答，答不上来的问 AI，不该答的转人工。

0 · AI 后端（可留空）

当前：纯本地匹配模式（只用知识库，不联网）

留空 = 纯本地模式，只用知识库回答，不花一分钱。
填上 = 启用 AI 兜底：本地答不上来的问题，转交大模型按知识库作答。
本地跑后端：cd server && node local-server.mjs → 然后打开 http://localhost:8787

打不开聊天窗？ 直接双击这个文件，浏览器会因为安全策略读不到知识库。 在 widget/ 目录下跑 python -m http.server 8000 即可。 想看 AI 兜底的效果，访问仓库主页的在线 Demo。

1 · 应该自动回答的（11 条）

2 · 应该转人工的 —— 答完提示转人工（5 条）

3 · 绝对不许机器自己拍板的（4 条）

第 3 组涉及退款、赔付、承诺日期、议价。机器一律不给答案，直接转人工。

4 · 知识库里没有的 —— 交给 AI 兜底（6 条）

这一组本地匹配不上。没填后端地址时，它们会走「转人工」；填上地址后，会交给大模型作答。 其中最后两条（退款、折扣）即使走 AI，也会被服务端强制转人工 —— 这是双保险。
