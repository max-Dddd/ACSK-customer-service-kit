# 示例案例 · Etsy 定制手工店：把回复率从 88% 拉回 97%

> ⚠️ **脱敏示例。** 店铺信息与业务数据经虚构处理，仅用于说明诊断方法与效果口径。

文中涉及的平台规则（Star Seller 四条指标）为 Etsy 官方规则，可自行核对。

---

## 一、这家店什么情况

| 项 | 情况 |
|---|---|
| 平台 | Etsy |
| 品类 | 定制首饰、名字定制礼品 |
| 客单价 | $30–80 |
| 月订单 | 约 150 单 |
| 客服 | 一个人全包 —— 设计、生产、发货、回消息都是他 |
| 渠道 | Etsy 站内消息 |
| 语言 | 英语 |

## 二、漏在哪

Etsy 的 Star Seller 有**四条硬指标**，其中一条直接卡客服：

| 指标 | 要求 |
|---|---|
| 消息回复率 | **95% 的首条消息，24 小时内回复**（含周末、节假日） |
| 按时发货 | 95% 订单在承诺处理时间内发出，带有效追踪 |
| 平均评分 | ≥ 4.8 |
| 最低活跃度 | 3 个月内 ≥ 5 单且 ≥ $300 |

几个要命的细节：

- **24 小时从买家发出消息那一刻算起**，不是从你看到算起。周五晚 11 点来的消息，周六晚 11 点前必须回。
- **只算每个会话的第一条消息**，后续来回不计。
- **自动回复计入回复率** —— 这条最关键，但多数卖家没用上。
- 每月 1 日评估，看**滚动 3 个月**的数据。掉一次，要三个月才洗得干净。

这家店的问题就出在这儿：

- 月消息量 **148 条**，大部分集中在晚间和周末
- 当前首条回复率 **88%**，已经跌破 95% 线
- 白天在赶工，消息往往堆到晚上才回；周末更慢
- 更要命的是，**回复率一旦掉，徽章当月就没了**，搜索权重跟着掉

## 三、做了什么

1. **知识库**：把定制规则、加工时长、国际运输、尺寸指南整理成结构化问答，覆盖五类高频问题 —— 改定制、时效、国际运输与关税、尺寸、定制品退换。
2. **自动应答规则**（关键在第一条）：
   - **首条消息到达即自动应答** —— 哪怕只是一句「收到，我先看下您的要求」，也足以把 24 小时那条线托住
   - 改单请求 → 自动回复常见选项 + 转人工
   - 时效询问 → 自动回复加工时间表，**不承诺具体日期**
   - 纠纷、差评风险 → 立即转人工
3. **交付物**：知识库 + 自动应答规则 + 测试报告 + 维护说明。

## 四、结果

上线一个月后的对照（同一店铺，前后各一个月）：

| 指标 | 上线前 | 上线后 |
|---|---|---|
| 首条消息 24h 回复率 | 88% | **97%** |
| 24h 内首响中位数 | 9.5 小时 | **40 分钟** |
| 每月花在重复问题上的工时 | 约 3.1 小时 | **约 0.4 小时** |
| 需人工介入的消息占比 | 100% | **约 58%** |

> 口径说明：可自动回答的消息按 62 条/月计（占总量 41.9%），单条人工处理耗时按 3 分钟计 —— 62 × 3 ÷ 60 ≈ 3.1 小时。
> 机器不碰的两类问题（改单、纠纷）100% 转人工，所以人工介入比例降不到很低 —— 这是设计如此，不追求「全自动」。
