# 场景分析 02 · Etsy 定制手工店（Star Seller 回复率）

> 本文不谈具体客户，只谈这类店的**结构性特点**：平台规则怎么把回复速度变成硬指标、套进去该怎么做。
> 规则以 Etsy 官方帮助中心为准，平台政策会变，引用前请自行核对。

---

## 一、为什么选这个场景

Etsy 的 Star Seller 徽章有**四条硬指标**，其中一条直接跟客服挂钩：

| 指标 | 要求 |
|---|---|
| 消息回复率 | **95% 以上的首条消息，24 小时内回复**（含周末和节假日） |
| 按时发货 | 95% 的订单在承诺处理时间内发出，且带有效追踪 |
| 平均评分 | ≥ **4.8** |
| 最低活跃度 | 3 个月内 ≥ 5 单且 ≥ $300 |

几个关键细节，决定这门生意为什么成立：

- **24 小时从买家发出消息那一刻算起**，不是从你看到算起。周五晚上 11 点来的消息，周六晚上 11 点前必须回。
- **只在每个会话的第一条消息上算分**，后续来回不计。
- **自动回复计入回复率。** 这条最关键——但大部分卖家没用上。
- **低单量店最脆弱**：一个月只有 10 条消息，晚回 1 条 = 90%，直接跌破 95%，徽章当月就没。
- 每月 **1 日**评估，看**滚动 3 个月**的数据。掉一次，要三个月才能洗干净。
- Vacation Mode 期间收到的消息**不计入**回复率。

> 对一个月 150 单的手工店主，"24 小时内回 95% 的首条消息、含周末"是一条几乎没办法靠人力百分百守住的线。

来源：Etsy 官方 Star Seller 帮助页及公开解读。引用时说明是**平台规则**，不要写成"我们统计的"。

## 三、诊断会发现什么

### 4.1 要客户给的三样东西
1. Etsy 后台的**客服统计页**（消息回复率、回复速度）
2. 近 3 个月的消息记录导出
3. 店铺的定制规则、加工时间、退换政策

### 4.2 要算的账

| 指标 | 怎么算 |
|---|---|
| 当前消息回复率 | Etsy 后台直接读 |
| 当前平均回复时长 | 同上，重点拆出**夜间和周末**那段 |
| 距离 95% 红线还差几条 | (1 − 当前回复率) × 月消息数 |
| 每月消息总量 | 计数 |
| 可自动回答的比例 | 分类计数 ÷ 总量 |
| 徽章风险 | 回复率 < 95% 时，当月即失去 |

### 4.3 高频问题簇（定制手工店的典型结构）

1. **改定制** —— 能不能改颜色 / 尺寸 / 加名字 / 换字体？
2. **时效** —— 什么时候发货？能加急吗？赶得上 X 月 X 日吗？
3. **国际运输与关税** —— 发不发我的国家？关税谁付？
4. **尺寸** —— 手围怎么量？项链选多长？
5. **定制品退换** —— 定制的能退吗？做错了怎么办？

## 四、交付了什么

- **知识库**：定制规则 + 加工时间 + 国际运输 + 尺寸指南，做成结构化问答
- **工作流（关键在第一条）**
  - **首条消息到达即自动应答**——哪怕只是一句"收到，我先看下您的要求"，也能把 24 小时那条线托住
  - 改单请求 → 自动回复常见选项 + 转人工
  - 时效询问 → 自动回复加工时间表，**不承诺具体日期**
  - 纠纷 / 差评风险 → 立即转人工
- 交付物：知识库 + 自动应答规则 + 测试报告 + 维护说明

## 六、怎么用这份分析

这不是一份"看别人怎么做"的案例，而是一张**照着你自己的店填的体检表**：

1. 对照第三节的问题簇，看看你自己的客服记录里哪几类问得最多
2. 套第四节的算法，把你店里真实的数字代进去
3. 算出来的工时和流失，就是这套东西对你有没有用的答案

> 每一处标「以实际为准」的地方，都该用你自己的数据替换。数字不实，结论就没意义。
