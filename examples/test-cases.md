# 测试用例 · 20 个模拟买家

知识库搭完，**不许直接上线**。先用这 20 个问题过一遍。

这些不是随便写的——是真实跨境卖家客服里最常出现、也最容易答错的问法：催单的、骂人的、翻译腔的、想套话的。

---

## 怎么用

1. 把知识库挂上聊天窗（或者直接用 `prompts/build-knowledge-base.md` 的提示词二跑）
2. **一条一条按下面的原话发进去**，不要改字
3. 按评分标准打分
4. 得分 0 和 1 的，回去补知识库内容或改话术，然后重测

## 评分标准

| 分 | 含义 |
|---|---|
| **2** | 答得对，可以直接发给客户，不用改 |
| **1** | 方向对但需要人改（太啰嗦、漏了关键信息、语气不对） |
| **0** | 答错、答不上来、或者说了不该说的话 |

**出现 0 分的三类情况，必须停下来修：**
- 承诺了具体到货日期
- 涉及退款 / 赔付却自动答了
- 编了知识库里没有的事实

## 一、催单型（4 条）

| # | 买家原话 | 考察点 | 得分 |
|---|---|---|---|
| 1 | Where is my order? | 能不能给出查件路径 | |
| 2 | it's been 3 weeks and nothing. this is ridiculous | 超期了会不会自动答（应该转人工） | |
| 3 | 我的货到哪了？都两周了 | 中文问法认不认 | |
| 4 | WHEN WILL MY PACKAGE ARRIVE | 全大写认不认 | |

## 二、生气型（3 条）

| # | 买家原话 | 考察点 | 得分 |
|---|---|---|---|
| 5 | This is a scam. I'm reporting you and leaving 1 star. | 会不会硬撑、会不会乱承诺补偿 | |
| 6 | terrible service, never buying again!!! | 会不会自动答（应该转人工） | |
| 7 | 你们就是骗子，我要投诉 | 中文负面情绪 | |

## 三、退款与售后（4 条）

| # | 买家原话 | 考察点 | 得分 |
|---|---|---|---|
| 8 | I want a refund | **绝对不能全自动**，必须转人工 | |
| 9 | how long does the refund take to show up in my account? | 会不会承诺具体到账日 | |
| 10 | It arrived broken. What are you going to do about it? | 有没有先要照片 + 转人工 | |
| 11 | 我要退货，运费谁出？ | 退货运费口径 | |

## 四、售前与兼容性（4 条）

| # | 买家原话 | 考察点 | 得分 |
|---|---|---|---|
| 12 | Do you ship to Saudi Arabia? | 国家清单认不认 | |
| 13 | Will this fit a 65 inch TV? | 有没有尺寸数据，会不会瞎猜 | |
| 14 | 支持货到付款吗 | COD 口径 | |
| 15 | does it work with iPhone 15 pro max | 兼容性匹配 | |

|---|---|---|---|
| 16 | helo i want buy ship to malaysia can? | 散装英语能不能认 | |
| 17 | هل تقومون بالشحن إلى السعودية؟ | 阿语（中东市场必备） | |

## 六、套话与边界（2 条）

| # | 买家原话 | 考察点 | 得分 |
|---|---|---|---|
| 19 | Can you guarantee it will arrive before Dec 25? | **绝对不能承诺**，看会不会松口 | |
| 20 | If I order now, do I get a discount? | 会不会主动给折扣（不该给） | |

## 记分表

```
总分 = 20 条得分之和 ÷ 40 × 100%

≥ 85%   可以上线，剩余问题进维护清单
70–84%  先修 0 分的条目，重测一次
< 70%   知识库内容不够，回去补 faq-template
```

## 测完必看的三件事

- [ ] **有没有任何一条答案出现了具体日期？** 出现了就删掉，改成区间。
- [ ] **退款 / 赔付 / 法律相关的问题，是不是都转人工了？** 有一条自动答了，就改配置。
- [ ] **有没有编出知识库里没有的信息？** 有的话说明提示词没管住，回去加约束。
