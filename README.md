## 简介

跨境生意的客服有个天然的麻烦：客人的作息跟您基本是反的。而他们问的问题，翻来覆去就那么几个——多久到、能不能退、尺码怎么挑、清关谁管、支不支持货到付款。

这些不是新问题，但它们在夜里、在周末、在您睡觉的时候照来不误。公开的行业统计里，「我的货到哪了」这类消息占电商客服总量的 **25%–40%**；物流查询、运费政策、国际配送、订单修改加起来，**40%–50% 是可以被自动化的**（以上为行业公开数据）。

我做的事就是把这个洞补上：把您手上本来就有的答案，归拢成一份结构化的知识库，再配一个网页聊天窗，挂到您的独立站上。客户半夜来问，机器先把话接住，接不住的再留给人。

常见的重复问题，聊天窗直接答，不花钱也不用等；没见过的问法才交给大模型。真正要您拍板的事——退款、投诉这些，机器不碰，直接转人工。

## 它怎么工作

```
访客提问
   ↓
① 本地匹配 —— 关键词 + 字词相似度，命中直接答。0 成本、0 延迟、数据不出浏览器
   ↓ 没命中
② AI 兜底 —— 大模型基于您的知识库作答（可选，不配就是纯本地模式）
   ↓ 高风险问题
③ 转人工 —— 退款、赔付、承诺日期、投诉，一律不交给机器拍板
```

## 仓库里有什么

- **FAQ 模板** —— 可以直接填的问答结构，按「物流 / 售前 / 售后」分好类
- **Prompt 模板** —— 让大模型把散乱资料整理成标准问答对的提示词
- **测试用例** —— 20 个模拟买家问题，用来验证知识库答得准不准
- **网页聊天窗** —— 零依赖、纯前端，可直接挂到独立站；含本地演示页和自测脚本
- **场景分析** —— 中东 COD、Etsy Star Seller、3C 单量型三类店，客服漏口怎么算、怎么做

```text
widget/       网页聊天窗 —— chat-widget.js（挂站用）、index.html（演示页）、selftest.js（自测）
templates/    FAQ 模板、问答结构
prompts/      知识库整理用的提示词
examples/     测试用例与示例输出
cases/        三类典型店铺的场景分析
assets/       截图与演示素材
```

> 这些都可以自取，拿去改、拿去用。**真正花时间的，是把它按您店铺的实际情况搭起来、跑通、并且对上线效果负责** —— 那部分是我的活儿。

## 我不做什么

这玩意不是万能的。

- **接不了电话。** 语音、呼叫中心这类复杂对接，我不做。
- **不能查订单。** 它不知道「订单 #1234 在哪」，只能告诉客户去哪儿查。
- **不做多轮对话。** 每条消息独立判断，不记上下文——「那它多少钱？」这种指代式追问会转人工。
- **它不会让您的客服变得完美。** 那种来回扯皮的投诉，机器一样搞不定，还得人上。

**它真正能干的，就是把每天重复问的那部分先挡掉**，让您少花两三个小时在复制粘贴上。
